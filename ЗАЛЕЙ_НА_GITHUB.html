Залить Холст на телефон через GitHub

Камера на телефоне работает только по https. GitHub Pages даёт https. После установки иконки компьютер не нужен.

Шаг 1. Войди

Открыть вход в GitHub

Шаг 2. Создай репозиторий

Создать репозиторий
  1. Repository name: holst
  2. Public
  3. Без README / .gitignore / license
  4. Create repository

Шаг 3. Залей файлы

  1. uploading an existing file
  2. Папка Desktop\ЯН\holst-pwa → выдели всё, кроме папки scripts если не хочешь её, и перетащи
  3. В корне должен быть index.html
  4. Commit changes

Шаг 4. Pages

  1. Settings → Pages
  2. Branch: main, папка / (root)
  3. Save → подожди 1–2 минуты

Шаг 5. Ссылка на телефоне

https://yanmag933.github.io/holst/

Safari / Chrome → Поделиться → На экран «Домой». Дальше открывай иконку «Холст» — без компьютера и можно без интернета.
